## 1. 抉择储「天际钻头」没优先让瓦皮承伤 —— **先取证，未改行为**

反编译 0.113 的链路（和本模组没有交集）：

```csharp
// CreatureCmd.Damage 内部
decimal modifiedAmount = Hook.ModifyDamage(...);                 // 力量/虚弱/易伤
Creature creature = originalTarget.PetOwner?.Creature ?? originalTarget;
Creature preBlockTarget = Hook.ModifyPreBlockDamageTarget(combatState, originalTarget, amount, props, dealer);
if (preBlockTarget != null) { preBlockTarget.LoseHpInternal(...); damageRemaining = OverkillDamage; }
decimal blockedDamage = creature.DamageBlockInternal(damageRemaining, props);   // 玩家只吃溢出
```

```csharp
// WuppysLoyaltyPower.ModifyPreBlockDamageTarget   （0.113 才有这个类型；0.111 参考程序集里没有）
if (originalTarget != Owner.PetOwner?.Creature) return target;   // 只替主人承伤
if (Owner.IsDead) return target;                                 // 瓦皮死了就不挡
if (!props.IsPoweredAttack()) return target;                     // 只挡强化攻击（Move 且非 Unpowered）
return Owner;
```

这条链**不经过 `HittableEnemies`、也不经过 `AttackCommand` 选靶** ⇒ 我们的选靶类补丁改不动它。
所以「不承伤」只可能来自三条之一：① 目标不是瓦皮的主人（打的是别人 / 打的是宠物）；
② 伤害不是强化攻击；③ 瓦皮已经死了。

⚠ 本模组这里特别容易踩 ③：日志实证抉择储那一手是 `cost 8` ⇒ X=8 ≥ 4 ⇒ **16 段 × 8 点**，
瓦皮血量低时前几段就被打死，后面每一段都直接落到玩家身上。

⇒ 本轮只加**诊断**：`src/Hooks/Patches/WuppyRedirectTracePatch.cs`（反射挂载，0.111 没有瓦皮就安静跳过）。
复现时日志里会有 `[CharBoss] 瓦皮承伤诊断：出牌者=… 原目标=… props=… 强化攻击=… 瓦皮HP=… 主人=… ⇒ 结论`，
一次就能定性。**确认原因后再决定要不要动行为。**

## 2. 终结技在多人被显示成群体伤害 —— 已修

`SilentBlades.RecomputeFinisherIntents` 以前把整份意图**覆盖**成 `AttackIntent.Multi(perHit, hits)`，
而「意图按人清零」（打的是别人 ⇒ 对本地玩家显示 0）只存在于 `BossIntentBuilder.IntentsFor` **自己建出来的**
那些意图里 ⇒ 覆盖后清零被抹掉 ⇒ 每个玩家的手牌栏都显示同一个真实数字 ⇒ 看起来像群攻。

修法：重算时走同一把尺子 `BossIntentBuilder.IsAimedAwayFromLocal(card, target)`（新加的 internal 包装），
打别人 ⇒ `RawAttackIntent(0)` + 一行日志，与其它攻击牌一致。

## 3. 群蛇形态多人又随机打玩家 —— 已修（根因：反射字段名写错，整段从未执行）

```csharp
public sealed class SerpentFormPower : PowerModel
{
    private class Data { public readonly Dictionary<CardModel,int> amountsForPlayedCards = new(); }
    protected override object InitInternalData() => new Data();
}
```

字典是**嵌套 `Data` 类**的字段，`SerpentFormPower` 类型上没有同名字段。
v0.2.888 写的 `power.GetType().GetField("amountsForPlayedCards")` ⇒ **永远 null**
⇒「自行结算」一次都没跑过（日志实证：整份 mod_log 里 `群蛇形态：自行结算` 出现 **0** 次，
`收窄到锁定` 也是 0 次）⇒ 原版 `Rng.CombatTargets.NextItem(HittableEnemies)` 照旧执行。

修法：`PendingDamageDict` 改成 ① `PowerModel._internalData` → ② 在该对象里找唯一的 `IDictionary` 字段
→ ③ 兜底扫 power 自身字段；取不到就**报一行**（不再静默）。拿到表后照 v0.2.888 的设计自行结算给锁定玩家。

## 4. 彩虹机用「模仿学习」复制了自己的扩容（+4 球位）—— 已修

```csharp
// ImitationLearning.OnPlay
p = await PowerCmd.Apply<ImitationLearningPower>(ctx, Owner.Creature, 2, Owner.Creature, this);
p.PlayerTarget = cardPlay.Target.Player;     // 目标 = 这张牌的出牌目标
// ImitationLearningPower.BeforeCardPlayed：cardPlay.Card.Owner == _playerTarget 且是能力牌 ⇒ 复制
```

`ImitationLearning` 是 `TargetType.AnyAlly`，而 `BossPlanner.ChooseTarget` 对「不是敌人的目标类型」一律
`return self` ⇒ 目标是**她自己** ⇒ `PlayerTarget` = 她自己的影子玩家 ⇒ 她每打一张能力牌就复制一张
（扩容 2 + 复制 2 = 4 个球位）。

修法：`Patches/ImitationLearningBossPatch.cs` —— 我们 Boss 打出时跳过原版那半（`__result = Task.CompletedTask`），
「挑在场的另一只 Boss + 记 2 张 + 下回合免费打」仍由 `Core/RainbowMimic` 负责（用户 2026-11-07 的设计）。
真人玩家打出这张牌时原版行为不变。

## 5. 玩家的鬼祟不生效（只在 Boss 打出攻击牌时生效）—— 已修（两处叠加）

- `SneakyOnlyBossAttacksPatch`（2026-10-29 为**奇巧猎自己的**鬼祟写的）没判「这份鬼祟是谁的」
  ⇒ 连真人玩家的鬼祟也掐掉了。日志实证：
  `鬼祟：真人玩家 P#14a04f 打出攻击牌 STRIKE_IRONCLAD → **不触发**`。
  ⇒ 现在只对「持有者是我们 CharBossMonster」生效。
- `SneakyOnBossAttack` 把**真人玩家**也算进补偿名单 ⇒ 我们 Boss 打出攻击牌时反而给玩家补了一笔格挡。
  ⇒ 现在补偿只给我们的 Boss（影子玩家的扇出真的漏）；真人玩家那条原版本来就会派发。
- 顺带修 `SneakyPowerEnemyBossIsNotTeammatePatch`：`Task` 方法前缀 `return false` 时补
  `__result = Task.CompletedTask`（不补会让原版 `await` 一个 null Task），并只对「持有者是真人玩家」生效。
