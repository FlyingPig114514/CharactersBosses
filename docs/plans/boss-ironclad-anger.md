# 一层 Boss「愤怒战」（铁甲战士）— 设计与实现

> 用户口述（2026-10-23），本文件是唯一权威记录。**暂时把一层 Boss 固定成他**。

## 1. 设计原文

- **特殊效果：群情激奋（全局）**
  1. 每当**铁甲战士打出「愤怒」**时，也向**所有玩家的弃牌堆**加入一张愤怒的复制品；
  2. 每当**有玩家打出「愤怒」**时，铁甲战士**本回合失去 3 点力量**
     （2026-10-23 用户把 1 点改成 3 点；仍用「黑暗镣铐」的 debuff = `DarkShacklesPower`）。
- **遗物**：燃烧之血、涅奥的祝福、锚、卡戎之灰。
- **卡组**：好勇斗狠、打击×4、痛击、愤怒、烙印、坚毅。
- **进阶 8**：升级「坚毅」，获得「**护喉甲**」（2026-10-24 削弱：原为奥利哈钢）；**进阶 9**：升级「烙印」。
- **意图**（`被烧` = 被前一张「烙印 / 坚毅」的「消耗 1 张牌」烧掉）。用户 2026-10-23 重新整理：

| # | 卡 |
|---|---|
| 1 | 愤怒、痛击、打击（没费打不了） |
| 2 | 打击、坚毅、打击（被烧） |
| 3 | 好勇斗狠、烙印、打击（被烧） |
| 4 | 洗牌。烙印、愤怒+（洗牌前好勇斗狠捞）、痛击、打击（被烧） |
| 5 | 愤怒+（好勇斗狠捞）、坚毅、打击、愤怒（被烧） |
| 6 | 洗牌。愤怒+（捞）、坚毅、愤怒+、打击（被烧） |
| 7 | **烙印**、愤怒+（捞）、痛击、愤怒+（被烧） |
| 8 | 洗牌。愤怒+（捞）、愤怒+、坚毅、愤怒+（被烧） |
| 9 | **烙印**、愤怒+（捞）、痛击、愤怒+（被烧） |

「之后 **8～9** 循环」⇒ `LoopFrom = 8`、`LoopLength = 2`。

> **用户 2026-10-23 追加的削弱**：「削一下，把所有痛击换成打击」⇒ 第 1/4/7/9 回合的**痛击 `Bash` 全部换成打击 `StrikeIronclad`**，
> 卡组里那张痛击也换成打击（共 5 张打击）。
> ⚠ 能量影响：第 1 回合变成 愤怒(0)+打击(1)+打击(1) = 2 费 ⇒ **三张都打得出来**（原来「打击没费打不了」这条不再成立）；
> 第 4/7/9 回合各只用掉 1 费（原来用 2 费）⇒ 回合结束会剩 1 费（这些牌不在「有费就打」名单里，不会补打，因为补打只给灵魂骨）。

能量核对：铁甲战士基础 3 费 − 涅奥的祝福 1 = **2 费**，与每回合「必打卡的花费」完全对得上
（第 1 回合 愤怒 0 + 痛击 2 = 2 ⇒ 打击打不出；第 2 回合 打击 1 + 坚毅 1 = 2；
第 7/9 回合 烙印 0 + 愤怒+ 0 + 痛击 2 = 2）。

### 1.1 两条追加要求（用户 2026-10-23 第二次口述）

1. **烙印加力量的伤害预览要提前补**：烙印是 0 费「失去1生命、消耗1张牌、**获得 1 点力量**」。
   第 7/9 回合它排在最前面 ⇒ 后面那些攻击的预览要先把这 +1 力量算进去，
   等烙印真打出去、力量到账后**按同样数量撤回**（同一套「冻结池 + 增加多少撤多少」口径）。
   实现：`BossDamagePredictor.StrengthGainOf`（读 `PowerVar<StrengthPower>` 的 `Strength` 变量）
   + `BladesGrowth.RecomputeAll` 里逐张累计 `plannedStrength`、给后面的牌加 `strengthPending`，
   `CharBossMonster.PlayOne` 在牌结算完后 `PlannedStrengthGainedThisTurn += 增益`。
2. **拦掉「好勇斗狠」的随机捞牌**：剧本里已经把要捞的那张（愤怒+）写进手牌了，
   原版 `AggressionPower.BeforeSideTurnStart` 的「随机捞一张攻击牌进手并升级」会多出一张牌、还不可复现
   ⇒ `Patches/BossNoAggressionPullPatch.cs` 在它为真时整段跳过。

## 4. 待确认 / 风险

2. **好勇斗狠的随机捞牌**已按用户要求拦掉（剧本里写好了要捞的那张）。
3. **卡戎之灰** 靠 `Patches/BossRelicHookBridge.cs` 手动补跑才生效（日志 `卡戎之灰兜底`）；
   **护喉甲**（2026-10-24 取代奥利哈钢）和「数据磁盘」一样挂在 `AfterRoomEntered` 上
   ⇒ 由 `BossHookBridge` 在战斗开始时补 4 层覆甲（日志 `护喉甲：战斗开始 +4 层覆甲`）。
4. 群情激奋是**全局**：多人时对所有真人玩家都生效（不是「只对锁定者」）。
5. 烙印的 +1 力量预览是**通用**机制（任何剧本里「先加力量、后打攻击」的牌都吃），
   不影响其它 Boss（它们现有剧本里没有这种「正数加力量」的牌）。

### 1.2 群情激奋的后续修改（用户 2026-10-23 第三次口述）
1. **「自己打愤怒也算减力量」的 bug**：判定改成以**牌的归属**为准（`card.Owner == 影子Player` ⇒ 是她打的），
   不再只看 `cardPlay.Player`（对她 `CardCmd.AutoPlay` 出来的牌，那个值可能是本地玩家/空）
   ⇒ 她自己打愤怒**不再扣自己力量**，攻击预览不再偏低。
2. **数值按人数分摊**：`StrengthLossPerAnger(realPlayerCount)`
   = 1 人 → **3**（单人不变）/ 2 人联机 → **2** / 3～4 人 → **1**（用户明确说多人未实装，先按 1 记着）。
   日志会带人数：`群情激奋：玩家打出 ANGER → 铁甲战士本回合失去 2 力量（2 人局；…）`。

### 1.3 藏品牌的关键词（用户 2026-10-23）
掉落/绑定的藏品牌统一补上 **虚无（Ethereal）+ 消耗（Exhaust）**（`DownfallCollectibleCompat.CreateCard` 里加，
已有就不重复加）。
