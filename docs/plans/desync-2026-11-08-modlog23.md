# 不同步日志分析：`mod_log (23).txt`（2026-11-08，玩家上报）

> 本人未参与，是其它玩家反馈。文件 8.9 MB / 75967 行 / 最后一次写入 **21:06:50**（当场刚打完就发了），
> 内容是 7 段会话拼在一起（旧日志没清）。

## 一句话结论

**不是新问题，但也不是「玩家版本旧」这么简单 —— 是我们打出来的包本身就是混版的。**

那份「刚刚打包」的 `CharacterBosses-v0.2.503.zip` 里：

| 包内文件 | 版本串 |
|---|---|
| `CharacterBosses.Impl107.dll` | **v0.2.503** |
| `CharacterBosses.Impl111.dll` | **v0.2.502** ← 旧 |

而这几名玩家跑的是 **beta（0.1.0+41cef1ea…，Loader 探测 beta=True ⇒ 加载 Impl111）**，
于是他们拿到的正是那个 **0.2.502** 的 beta 实现 —— `v0.2.503` 的多人阵容修复**从来没进过他们手上**。

⇒ 不是玩家懒得更新，是包里 beta 那份就是旧的。

## 混版是怎么来的

`install-mod.bat` 第 3 步用 `copy /Y … >nul` 复制 `Impl107/Impl111`，
**游戏开着时 DLL 被占用 ⇒ copy 失败，但错误被 `>nul` 吞掉**，脚本继续往下跑并调 `pack-dist.ps1`，
`pack-dist.ps1` 又是「把游戏目录那份原样搬过去」⇒ 107 是新的、111 还是上一版，包就这么混了。

（这次 107 是新的、111 是旧的也能反推：那次 install 只编/覆盖成功了 107。）

## 四次「不同步状态摘要」本身

摘要由原版 `ChecksumTracker.LogStateDivergence` 触发（真分叉，不是我们的探测误报）：

| 时间 | 当时版本 | 遭遇 | 本机生成 | 分叉轮次 |
|---|---|---|---|---|
| 19:46:49 | v0.2.497 | `REGENT_KING_BOSS_ENCOUNTER` | 2 只 `[REGENT_BOSS, IRONCLAD_BOSS]` | 1 |
| 20:29:22 / 23 | v0.2.497 | `IRONCLAD_JUGGLER_BOSS_ENCOUNTER` | 2 只 `[IRONCLAD_BOSS, REGENT_BOSS]` | 1 |
| 20:58:27 | v0.2.502 | `SILENT_BREWER_BOSS_ENCOUNTER` | 2 只 `[SILENT_BOSS, REGENT_BOSS]` | 3 |
| 21:02:13 | v0.2.502 | 同上（重开同一场） | 同上 | 3 |

这几场都是 **3 人局**，阵容分别是 `[…]` 里**同族重名**（`REGENT_KING×2`、`IRONCLAD_JUGGLER×2`、`SILENT_BREWER×2`），
去重后只剩 2 只 Boss ⇒ 「3 名玩家 / 2 只 Boss、第三位玩家锁定图标 0 个」**是设计内结果，不是 bug**。

轮次 1 就分叉，正是 `v0.2.503` 修的那个症状（多人时主 Boss 候选表也读本机勾选 ⇒ 两端阵容长度不同），
而这两段会话跑的都是没有该修复的代码。20:58 那次拖到轮次 3，是分叉后继续打的结果（中途玩家阵亡、锁定重分配），
`21:04:07 跟踪锁定同步：REGENT_BOSS → Ironclad…（原来锁的 Necrobinder 已阵亡/离场）` 是**设计内**行为。

## 已做的修复（防止再发出混版包）

`tools\pack-dist.ps1` 加了**打包护栏**：打包前读源目录两份实现的版本串（UTF-16 里的 `BuildInfo.Tag`），
只要有一份 ≠ `src\CharacterBosses.json` 的 `version` 就直接 `exit 1`，并提示「可能是游戏开着、copy 被占用，先退游戏重跑 install-mod.bat」。

该护栏立刻抓到了现网状态：

```
[dist] CharacterBosses.Impl107.dll 版本串: v0.2.507
[dist] CharacterBosses.Impl111.dll 版本串: v0.2.507
[dist] 已生成 CharacterBosses-v0.2.507.zip (13.13 MB)   ← 包内两份 dll 都是 0.2.507（已解压核对）
```
