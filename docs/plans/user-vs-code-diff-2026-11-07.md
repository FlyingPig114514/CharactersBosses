### 2）关于「循环是不是从 0 开始」

`BossScript.TurnAt(int turn)` 的实现是：

```csharp
int index = turn - 1;
if (LoopFrom > 0 && LoopLength > 0 && turn >= LoopFrom)
    index = LoopFrom - 1 + (turn - LoopFrom) % LoopLength;   // LoopFrom 按 1 起算
```

所以 **`LoopFrom` 是 1 起**。几个脚本的注释（与你的描述）按 0 起写，于是值比设计值小 1：
辉星储 `4`（应 5）、巨石战 `5`（应 6）、事件机 `5`（应 6）。
（电球机 `LoopFrom = 7` + 注释「7～10」是 1 起写的，所以它是对的；状态机、无色储君那几处也对。）
