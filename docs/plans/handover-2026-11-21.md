## 2. 怎么做一个 Boss 的地图图标

### 2.1 目标规格（照抄现有 14 个）

- **512×512 PNG**，`RGB` 全部 255（纯白），**形状在 alpha 通道**（游戏用 `modulate` 上色）
- 每张主图必须配一张 **`<name>_outline.png`**（描边版：对 alpha 做 `OutlineBand` 像素膨胀再减掉原图）
- 放在 `tools\art\import_proj\CharacterBosses\images\map\`，并在 `tools\art\pck_extras.txt` 里登记（含 `.import`）
- 游戏内路径：`res://CharacterBosses/images/map/<name>`（不带扩展名）

### 2.2 三条路线（现有脚本都在这）

**A. AI 从零生成（txt2img）—— 41 只都已经写好了提示词**

- `tools\art\prompts.md`：固定风格前半段 + 41 只的主体句、负向词、推荐参数（SD1.5、512×512、DPM++ 2M Karras、25 步、CFG 7、每张出 4~6 张挑 1 张、同批固定种子）
- 出图后按 **`<KEY>.png`**（如 `SILENT_SLY.png`）放进 `tools\art\raw\`
- 然后跑 `tools\art\make-silhouette.ps1 -InDir tools\art\raw -OutDir <images\map> -Ink Black -Threshold 128 -Soft 48 -Trim`
  （`-Ink Black` = 白底黑图；`-Ink White` = 黑底白图；`-Size 512`）

**B. 结构拼接（不用 AI）—— `tools\art\compose-icon.ps1`**

脚本头部把设计意图写得很清楚：这些图标本质是「底图 + 头像」的结构合成（墓碑底座 + 角色头像、刀环 + 头像、光环 + 头像），
而零件本身就是游戏原版的单色剪影 ⇒ **直接拼最准、风格天然统一**，SD1.5 纯 txt2img 反而不可控（实测它会照字面去搜「墓碑」出成照片）。

每一步怎么处理（脚本里逐条实现）：

1. 读参考图（`tools\art\refs\`，如 `avatar_ironclad.png`、`card_rage.png`）→ 取剪影（有 alpha 用 alpha，否则按亮度阈值）
2. 裁到内容包围盒
3. 按配方缩放（fit width / fit height）并定位（anchor top / bottom / center）
4. 可选 `punch`：清空画布中心一个圆 —— 用来把卡图中央的角色挖掉，只留外圈光环/刀环
5. 所有层按 **alpha 取最大值**叠加（= 剪影并集）

用法：`compose-icon.ps1`（全做）/ `-Only NECROBINDER_DOOM`（只做一只）；输出到 `tools\art\compose\`，同时出一张预览拼图 `tools\art\preview\compose_sheet.png`。

**C. 拼接 → AI 润色（你说的「纯拼接效果一般」，就是这条）**

现有两个脚本正好是为这个流程写的：

```powershell
# 1) 先拼出草稿（B）
powershell -ExecutionPolicy Bypass -File tools\art\compose-icon.ps1 -Only DEFECT_THUNDER

# 2) 压平成「白底黑剪影」并直接拷进 ComfyUI 的 input 目录
powershell -ExecutionPolicy Bypass -File tools\art\flatten-for-img2img.ps1
#   默认 InDir=tools\art\compose  OutDir=tools\art\compose_flat
#   ComfyInput 默认 D:\AI\ComfyUI_windows_portable\ComfyUI\input（路径变了就改参数）

# 3) ComfyUI 里用 tools\art\comfyui-sd15-img2img.json 做 img2img
#    - 提示词直接用 prompts.md 里对应那只的 positive/negative
#    - denoise 建议 0.30~0.45（这个值在 ComfyUI 工作流里，脚本里没有；先 0.35 试）
#      ⚠ 这条是建议值，本会话没实测过 —— 每只都要看预览，denoise 太高会丢掉结构
# 4) 出图 → 丢回 tools\art\raw\<KEY>.png → 走 make-silhouette.ps1 变回游戏规格
powershell -ExecutionPolicy Bypass -File tools\art\make-silhouette.ps1 -InDir tools\art\raw -OutDir tools\art\import_proj\CharacterBosses\images\map -Ink Black -Trim
```

**为什么必须有第 2 步（flatten）**：ComfyUI 的 `LoadImage` 会把 RGBA 的 alpha **丢掉**（`convert("RGB")`），
我们游戏图标恰恰是「白 + alpha」⇒ 它看到的是一张**纯白图**，img2img 完全没有构图参考。`flatten-for-img2img.ps1` 把 alpha 反压成黑色 ⇒ 白底黑剪影，正好对上提示词里的 "pure black ink shape on plain white background"。

### 2.3 清理杂块（几乎每张都要跑一次）

`tools\art\clean-icon.ps1 -In <源> -Out <目标>`：按**连通块**的大小 / 位置 / 胖瘦（实心度 = 面积 ÷ 包围盒面积）丢掉不要的碎片。

- 「火焰纹」火环两侧飘散的火絮 → 用「质心 x 太靠边」
- 「地狱狂徒」刀环里混着卡图自带的烟云 → 用「实心度」（细长刀约 0.15~0.35，团状烟云 0.5+）

现存的一次性脚本可以当模板抄：`make-wrath-fire.ps1`、`make-strike-blades.ps1`、`make-dart-oriented.ps1`、`make-flame-wreath.ps1`、`make-snakebite-icon.ps1`、`make-soul-bone-icon.ps1`、`make-fool-icon.ps1`（愚者：白剪影 + 把绿色眼睛挖空 + 描边）。

### 2.4 打包与接线（漏了就等于没做）

1. **登记**：`tools\art\pck_extras.txt` 里加 4 行（主图 / `_outline` / 两个 `.import`），格式照抄已有行（`res://...\map\x.png|<绝对路径>`）
2. **重打 pck**：`install-mod.bat`（`[4/4] Creating .pck file`）

   - `TierBossEncounters.cs:35`（愤怒战）等

   - ⚠ 「兜底徽章那段代码的具体位置」本会话没有复核（grep `images/map/` / `OurBadge` 能找到），接手时先确认一遍。

### 2.6 踩过的坑（省你时间）

- **纯 txt2img 不受控**：SD1.5 会把「tombstone」当实物去画。结构类图标优先走 B/C。
- **alpha 会被 ComfyUI 丢掉** ⇒ img2img 前一定先 `flatten-for-img2img.ps1`。
- **描边不是描线**，是「alpha 膨胀 N 像素 − 原图」，见 `make-fool-icon.ps1` 的 `-OutlineBand`。
- **RGB 必须全 255**：游戏靠 `modulate` 上色，图里带颜色会显得脏。
- 拼接出来的层要用「alpha 取最大值」合并，不能直接 `DrawImage`（会把下层 alpha 覆盖掉）。
- 图标文件名是**小写 + 下划线**（`ironclad_strike`），游戏按 `res://.../map/<name>` 找，大小写错了会静默退回兜底。
