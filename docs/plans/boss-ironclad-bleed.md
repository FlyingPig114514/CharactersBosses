## 4. 特殊效果「扯碎」（`Powers/BossRendingPower.cs`）
原版「撕裂」的条件写死成「在**你的回合**内失去生命」⇒ 玩家回合里那点零星掉血

一点都喂不动。这条补上：**不在他回合**失去生命、且**单次 ≤ 5** ⇒ 自己重放一次
· 撕裂（有 N 层 ⇒ 力量 +N）

（单次 > 5 不接，避免玩家一大刀让他一次叠一堆力量。）

### 4.1 2026-10-28 削弱（用户：**把狱火换成岩石铠甲，特殊效果描述里去掉狱火**）
· 剧本第 3 回合：**狱火 → 岩石铠甲**（`StoneArmor`，1 费、4 层覆甲），卡组同步换掉；
· 扯碎**不再重放狱火**，只重放撕裂 ⇒ 这条效果现在纯粹是「小额掉血也叠力量」，
  不再对真人玩家产生任何额外群伤；
· 中英文案同步改：`monsters.json` 的 `IRONCLAD_BOSS.rending`、`powers.json` 的
  `BOSS_RENDING_POWER.description` 都只写「撕裂」。

### 4.3 意图里的「撕裂 + 自伤卡」力量（v0.2.80，用户 2026-10-28）
用户：「伤害预览有时不会计算自伤卡配合撕裂获得的力量」。

反编译口径：`RupturePower` = 「每当你在**你的回合内**失去生命 → 力量 +层数」，
而血墙/御血术/突破/烙印都是「**先**扣自己的血、**再**给格挡或打伤害」
（`CreatureCmd.Damage(…HpLoss…, Unblockable|Unpowered|Move, 自己…)` 排在 `DamageCmd.Attack` / `GainBlock` 之前）
⇒ 这笔力量对**它自己那一下**也算得上，对后面所有攻击牌当然也算得上。

实现（`BladesGrowth.RecomputeAll` 按剧本顺序走一遍，出牌期同一套）：
· `ruptureNow` 从她身上现有 `RupturePower` 层数起算，剧本打到「撕裂」那张时加上它的层数
  （`Rupture` 的 `Strength` 变量其实是 **RupturePower 的层数**，不是力量）；
· 每张**带 `HpLoss`** 的牌 ⇒ `ruptureHere = ruptureNow`：
  · 自己这一下：`rise += ruptureHere`（先掉血后结算）；
  · 后面的牌：`plannedStrength += ruptureHere`（真到账后由 `CharBossMonster` 按同样数量撤回）。

### 4.4 顺手修的「假力量」（同一次）
`BossDamagePredictor.StrengthGainOf` 以前把「撕裂」的 `Strength` 变量当成 +1 力量
（那是 `RupturePower` 的层数）⇒ 撕裂之后所有攻击预览凭空 +1。现在按 entry 排除，
真正的力量改由上面 4.3 那套记账。
### 4.2 全身撞击的**意图数字**（v0.2.77，用户 2026-10-28）
用户实测：「全身撞击的伤害没有考虑他在本回合会获得的格挡值」。

原因：`BodySlam` 的伤害是 `CalculatedDamageVar.WithMultiplier((card, _) => card.Owner.Creature.Block)`，
而意图是**玩家回合里**算的 —— 那时他回合开始该清的格挡还没清、本回合的血墙也还没打 ⇒ 显示旧值。
格挡在他**自己回合开始**会清空，所以「出手那一刻的格挡」=

  ① 回合开始到账的：绯红披风 `CrimsonMantlePower`（7/10）+ 自成型黏土 `SelfFormingClayPower`（每次未格挡伤害 +3 层）；
  ② 本回合剧本里**排在他前面**那些牌给的：`BlockVar`（血墙 16 / 坚毅 7 / 防御 5）。

实现：`BossScriptPlanner.Plan` 按剧本顺序累计 `simBlock`（`TurnStartBlockOf` + `BlockGainOf`），
遇到 `BODY_SLAM` 就把 `simBlock` 作为 `bodySlamBlock` 传给
`BossIntentBuilder.IntentsFor`，覆盖牌面伤害后照常过力量/虚弱/易伤管道。
出牌期（`CharBossMonster.Turn`）不用改：那时真实格挡已经到账。
## 5. 多人
· 剧本第 1／7 回合的「全身撞击+」在多人时换成「恶魔护盾+」
  （`MultiplayerCardSwap` A7 行 + `UpgradeRows` 强制升级）；
· **⚠ 剧本里只能写「全身撞击+」一张**（2026-10-28 用户实测）：
  第一版为了省事把「恶魔护盾+」也写进了第 1／7 回合，结果单人局手里同时有这两张 ——
  意图栏多出一条打不出去的恶魔护盾（`ChooseDemonicShieldTarget()` 单人返回 null ⇒ 跳过）。
  换牌是**替换**语义，不是追加。
· 恶魔护盾的**目标**由 `CharBossMonster.ChooseDemonicShieldTarget()` 决定：
  同一侧活着的**其它 Boss**，先把储君排到最后（他在这之后才行动），再取格挡最少的那位；
  队友全倒了 ⇒ **这张牌不出**（日志会说明是「队友都倒了」还是「单人局」）。
