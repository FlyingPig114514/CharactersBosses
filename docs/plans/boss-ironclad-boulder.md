## 3. 能量账（剧本把每回合能量写死，见 `BoulderIroncladScript`）

基础 3 − 涅奥的祝福 1 + 血染玫瑰 1 + 面包 1 = **4 / 回合**；面包首回合 −2 ⇒ 首回合 **2**。
但首回合要打出「执迷(2) + 无惧疼痛(1)」= 3，所以第 1 回合**按 3 写死**
（祭品给的 +2 是回合内到账，不进预算；这与其它 Boss 的处理一致）。

| 回合 | 能量 | 账 |
|---|---|---|
| 1 | **3** | 执迷 2 + 无惧疼痛 1；祭品(0) → 原始力量(0) |
| 2 | 4 | 头槌 1 + 坚毅 1；彼岸咆哮在回合结束时自己打出（不花费用） |
| 3 | 4 | 腐化+ 2 + 巨石 1 + 巨石 1；腐化让两张防御变 0 费 |
| 4 | 4 | 战斗专注 0、防御×2 0（腐化）、坚毅 0（腐化）、巨石 1 |
| 5（循环） | 4 | 执迷 2 + 巨石 1 + 巨石 1 = 4 正好花完；彼岸咆哮(3) 与另外两张巨石没费 |

## 5. 实现要点

1. **特殊效果「原始力量」**：`src/Hooks/Powers/BossPrimalForcePower.cs`
   * `AfterCardPlayed`：她自己打出 `GIANT_ROCK` ⇒ `StrengthPower +1`、`PlatingPower +2`，
     并**自己补等量格挡**（原版 `PlatingPower.BeforeSideTurnStart` 对我们的 Boss 是压掉的，
     与护喉甲同一套处理，见 `BossHookBridge.GrantGorgetPlatingAtCombatStart`）。
   * `AfterDamageReceived`：`dealer == 她` 且 `cardSource` 是巨石、目标是真人玩家、
     `DamageResult.UnblockedDamage > 0` ⇒ 给那位玩家 **1 层虚弱**（被格挡全挡住就不给）。
   * 类名带 `Boss` 前缀是硬要求（模型 id 由类名算，撞名会让游戏起不来）。
2. **彼岸咆哮**：`HowlFromBeyond.AfterAutoPostPlayPhaseEntered` 只对真人玩家派发 ⇒
   新增 `BossTurn.FreePlayExhaustEntry`（与「所向无敌」的 `FreePlayTopEntry` 同一个钩子），
   在第 2 / 第 4 回合的回合结束时，从**消耗牌堆**里找到它并调它自己的实现。
3. **巨石**从哪来：原始力量是真实的原版卡，打出时会把**手牌里的攻击牌**变成巨石；
   剧本里第 1 回合那两张被变出来的巨石用 `DisplayOnly` 造出来（只展示、不出牌），
   第 3 / 5 回合的巨石由剧本直接写出（`From = "deck"`）。
4. **三层双设计**：`BossDefs.Ironclad.VariantsByAct[2]` = 巨石战，
   `Enabled = BossLineups.BoulderActive`（**以房间遭遇为准**，拿不到才按种子 50/50：
   `BoulderAt3()` = `Roll(2, 43, 2) == 1`）。三层铁甲战士的**档位遭遇**由
   `CharBossEncounters.TierEncounterFor` 按 `BoulderAt3()` 在「易伤战 / 巨石战」之间选。
5. **遭遇 / 阵容**：`IroncladBoulderBossEncounter`（`TierAct = 2`）、Key `IRONCLAD_BOULDER`
   （追加到三层候补末尾，三层变 7 个：刀猎 / 能力机 / 根除骨 / 无色储君 / 易伤战 / 炼药猎 / 巨石战）、
   控制台 `fight IRONCLAD_BOULDER_BOSS_ENCOUNTER`。
6. **图标**：特殊效果 Power 借用原版「好奇」的灯泡图标
   （`BossSpecialPowerIconPatch` 白名单已加 `BossPrimalForcePower`）；地图图标暂用基类占位。
7. **本地化**（中英各一）：`IRONCLAD_BOSS.boulder`、`BOSS_PRIMAL_FORCE_POWER.*`、
   `IRONCLAD_BOULDER_BOSS_ENCOUNTER.title/loss`。
