# 用网盘分发离线包（夸克 / 蓝奏 / 百度 …）

> 场景：有玩家上不了创意工坊（或工坊更新卡住），需要一份**能直接解压进 `mods\` 的离线包**。
> 现成的包就在 `.dist\CharacterBosses-v<版本>.zip`（≈13 MB，含 4 个 DLL/清单 + pck + `安装说明.txt`）。

## 一、要传哪个文件

```
.dist\CharacterBosses-v0.2.451.zip      ← 当前线上版本，直接传这个
```

包内结构（解开就是 `mods\CharacterBosses\`，玩家不用自己新建目录结构）：

```
CharacterBosses\
  CharacterBosses.dll          11 KB   双版本外壳
  CharacterBosses.Impl107.dll  1003 KB 正式版实现
  CharacterBosses.Impl111.dll  998 KB  beta 实现
  CharacterBosses.json         1 KB    清单
  CharacterBosses.pck          12979 KB 资源（本地化/美术/音乐）
  安装说明.txt                  102 KB   给玩家的步骤（含 BaseLib 依赖说明）
```

> **只有明确说「打包」时才生成新 zip**（`tools\pack-dist.ps1`，或 `install-mod.bat pack`）。
> 版本号一变就要重打一份，别让网盘上的旧包和新版混着传。

## 二、网盘怎么选

| 网盘 | 优点 | 注意 |
|---|---|---|
| **蓝奏云（lanzou）** | 国内小文件最省事，**下载不用登录**、免客户端、速度快（单文件 ≤100 MB 免费） | 链接域名会换（lanzou*.com 轮换），换域名时旧链接可能失效，需要重发 |
| **夸克网盘** | 空间大、分享方便、玩家手里常装 | 部分场景下载需要**客户端/登录**；分享时别勾「仅会员可下载」 |
| **百度网盘** | 用户最多 | 非会员下载限速严重，13 MB 也会被限；不推荐做首选 |
| **阿里云盘** | 速度好 | 需要登录才能下载 |

**建议**：主用**蓝奏云**（玩家点开就能下），备用**夸克**（长期存档 + 空间够）。

## 三、操作步骤（以夸克为例，蓝奏同理）

1. 浏览器打开夸克网盘网页版 → 上传 `.dist\CharacterBosses-v0.2.451.zip`。
2. 右键该文件 → **分享** → 有效期选「**永久有效**」→ 生成链接（可选提取码，建议设一个四位数防爬虫）。
3. 复制**链接 + 提取码**，贴到这三个地方：
   - 创意工坊**描述**里（加一行「上不了工坊的可以下离线包：链接 提取码」）；
   - 你的 B 站视频/动态简介、QQ/微信群公告；
   - 直接回复那个找你反馈的玩家。
4. 每次发新版：**重命名带上版本号**（`CharacterBosses-v0.2.452.zip`），上传后用**同一个分享链接**
   （夸克里可以直接替换文件、链接不变；蓝奏要重新分享并把新链接重发一次）。

## 四、给玩家的说明模板（可直接复制）

> **离线安装（上不了创意工坊时）**
> 1. 先装前置模组 **BaseLib**（工坊物品 3737335127）。完全上不了工坊的话，让朋友把
>    `<游戏目录>\mods\BaseLib\` 整个文件夹打包发给你，放到同一位置。
> 2. 下载 `CharacterBosses-v0.2.451.zip`，把里面的 `CharacterBosses` 文件夹整个解压到：
>    `<Steam>\steamapps\common\Slay the Spire 2\mods\`
> 3. 启动游戏 → 主菜单「模组」里勾上「玩家角色Boss (Characters Bosses)」→ 重启游戏生效。
> 4. **联机必须所有人版本一致**（模组列表里能看到版本号）。不同步就把
>    `%APPDATA%\SlayTheSpire2\logs\mod_log.txt` 发给作者。
> 5. 卸载：删掉 `mods\CharacterBosses\` 整个文件夹。

## 五、检查清单（每次发包）

- [ ] zip 是从**当前已部署/已发布**的版本打出来的（`BuildInfo.Tag` = 文件名里的版本号）
- [ ] 解压后有 `安装说明.txt`，且里面第 1 行的版本号与包名一致
- [ ] 在**干净的**游戏上试一次解压安装（或至少确认四个 DLL/清单 + pck 都在）
- [ ] 分享链接设置：永久有效 + 允许下载（不勾会员限制）
- [ ] 工坊描述 / 群公告里的链接已更新（蓝奏换域名时要重发）
