## 4. 特殊效果「群星荟萃」（`Powers/BossStellarGatheringPower.cs`）

反编译：「保留手牌」不是卡牌关键字，而是一层 power ——
`Salvo` / `Convergence` / `Equilibrium` 都在 `OnPlay` 里
`PowerCmd.Apply<RetainHandPower>(ctx, 自己, 1, 自己, 这张牌)`，
真正「不丢手牌」由 `RetainHandPower.AfterSideTurnEnd` 做。

实现：本 power 挂在 `AfterPowerAmountChanged` 上，判断
**`power is RetainHandPower` + `power.Owner == 他` + 增加** ⇒ 对每个**真人玩家**
`Apply<RetainHandPower>(1)` + `Apply<EnergyNextTurnPower>(1)`。
（玩家拿到的那层 Retain 自己不会再触发本效果：`power.Owner` 不是他。）
