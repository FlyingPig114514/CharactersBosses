## 3. 特殊效果「原始力量」（重做）

- 他**使用巨石（`GiantRock`）时**：获得 **+1 力量** 与 **3 层覆甲**（`PlatingPower`）；
- 巨石对他造成**未被格挡的伤害**时：**玩家抽 1 张牌**。

（旧版是「巨石 +1 力量 +2 覆甲 + 等量格挡、未格挡巨石伤害给玩家 1 虚弱」，本版按上面这条覆盖。）

## 4. 剧本结构（8 回合，之后 6～8 循环）

- 第 1 回合有**腐化+**：此后所有技能牌 0 费且带消耗 ⇒ 第 3/5/6/8 回合的防御、坚毅等技能牌的能量账要按 0 费重算；
- 第 1 回合「原始力量+」会**变化**（transform）成 打击×2 + 痛击，巨石+ 打出后剩下的变化牌没有费用；
- 第 4 回合「彼岸咆哮」被坚毅+ 烧掉，**回合结束时从消耗堆打出**（沿用旧版的消耗堆自动打出逻辑）；
- 第 6 回合先洗牌，再 巨石+ / 头槌（捞巨石） / 铁斩波；
- 循环 6～8。
