# QQ 群公告 + 置顶报 Bug 模板

> 用途：新建玩家群后，**群公告**整段复制粘贴；**报 Bug 模板**设为群「置顶消息」，并在群公告里 @全体 指一次。
> 版本：对应模组 v0.2.899（2026-11-23）。改了报障流程再回来改这份。

---

## 一、群公告（整段复制）

```
【玩家角色Boss · 问题反馈与联机约战群】

一、先说三件事
1. 报 Bug 之前先看「置顶消息」里的模板，按模板发 —— 缺信息的帖子我基本没法查。
2. 更新模组后请**重启游戏**；多人联机**所有人的模组版本必须完全一致**，否则必定掉线/不同步。
3. 群里不发游戏本体、不发破解/代充/外链广告，看到直接撤回。

二、常用地址
· 创意工坊（更新都在这里）：
· 百科页（41 只 Boss 的卡组 / 遗物 / 逐回合剧本）：
· GitHub（源码 + 更新日志）：

三、日志怎么拿（都是小文件，不要发几十 MB 的整份日志）
· **游戏里按 F8** → 自动生成 characterbosses_recent.txt（最近 3000 行，几十 KB），直接发这个
  路径：%APPDATA%\SlayTheSpire2\logs\
· 崩溃 / 卡死 → 再补 characterbosses_trace.txt（逐行落盘，崩得再快也留得住）
· 按不了 F8 的备用办法：Win + R 打开 %APPDATA%\SlayTheSpire2\logs\ ，先把 mod_log.txt 改名，
  再复现一次，新生成的那个就是「这次问题」的日志（它是累积的，不删会很大）

四、速查
· 模组没加载 / 报「初始化失败」→ 确认 BaseLib 也装了、版本和游戏一致
· 多人打 Boss 时卡住不动 → 先看所有人版本是否一致，再按模板发「联机」那一类
· 觉得伤害/层数不对 → 发截图 + 说明第几回合、哪只 Boss、哪张牌（有日志更好）

五、想帮忙的
· 会玩、有耐心、能按模板追问细节的，私聊我申请管理员（只做三件事：收日志、催信息、把已解决的结论贴到置顶）
```

## 二、置顶消息：报 Bug 模板（整段复制，让玩家照着填）

```
【报 Bug 模板 · 直接复制，按项填，不用全填但要尽量全】

模组版本：0.2.xxx  （模组列表里那一行）
游戏版本：0.111 / 0.113（看主菜单右下或游戏属性）
单人 / 多人：单人 ｜ 多人（几人：2/3/4）｜ 我是房主还是客机
还装了哪些模组：BaseLib、崩坠、亡命之徒(HermitRework)、皮皮极速(SpeedX)、Champ Beta、其他____
哪一幕 / 哪只 Boss：第 1/2/3 幕 · 名字（例：第 2 幕 电球机）
哪张牌 / 哪个特殊效果：
现象一句话：
复现步骤：
  1.
  2.
  3.
有没有截图/录像：有（贴在下面）/ 没有

【下面按类型挑一段，附上对应文件】

▍A. 崩溃 / 闪退 / 卡死（游戏直接没了，或画面完全不动）
· 必发：%APPDATA%\SlayTheSpire2\logs\characterbosses_trace.txt
· 有的话再发：%LOCALAPPDATA%\CrashDumps\SlayTheSpire2.exe.*.dmp（崩完才有，文件名带时间）
· 再补：%APPDATA%\SlayTheSpire2\logs\godot.log 的**最后 100 行**
· 顺手按一下 F8（有些崩溃是「假崩溃」，其实进程还在，recent 里能看到最后在干嘛）
· 说清楚：卡死前你在做什么（点了结束回合？谁在出牌？有没有激发充能球？）

▍B. 数值 / 机制不对（伤害、层数、意图、卡牌效果）
· **必发：游戏里按 F8 导出的 characterbosses_recent.txt**（最近 3000 行，几十 KB）
  路径：%APPDATA%\SlayTheSpire2\logs\characterbosses_recent.txt
· 截图（带意图栏和血量）优先，比文字有用十倍
· 补充：第几回合、那只 Boss 身上有哪些 buff、你自己有哪些 buff
· 如果和「公式」有关，把你算出来的数和对不上的数都写上

▍C. 多人联机问题（掉线 / 不同步 / 看不到对方）
· **两端日志都要**（房主 + 客机各按一次 F8，各发一份 characterbosses_recent.txt；崩过的再补 trace）
· 必写：所有人模组版本是否一致、是第几幕第几回合断的、断之前有没有人出过某张特定牌
· 若有「不同步」提示，截图那条提示

【不用发的】
· 整个 mod_log.txt（可能几十上百 MB）—— 上面那份 F8 导出的小文件就够
· 整份 godot.log（只要最后 100 行）
· 电脑配置、帧数（除非你怀疑是卡顿）
```

## 三、群规（贴公告第二段或单独一条）

1. 报 Bug 请按模板发到群里，或发到「群文件 / 问题反馈」文件夹；**别私聊发日志**，别人搜不到。
2. 不发游戏本体、破解、代充、外链广告；不讨论盗版。
3. 骂人可以骂我，不要骂报 Bug 的人。
4. 提问前先搜群文件与置顶，重复问题会被合并。
5. 管理员只负责收信息与催细节，不承诺修好时间 —— 我这边是**业余维护**。

---

## 四、管理员三件事（贴给管理员看，不用发群里）

1. **收料**：按模板缺什么就问什么，缺「模组版本 / 是否多人 / 复现步骤」的一律先补齐。
2. **归类**：把同一问题合并，给个编号（例：`#12 电球机崩溃`），方便我在 GitHub 里对上。
3. **回写**：问题查清后，把结论一句话贴到置顶（例：「#12 已定位：球没有主人导致空引用，v0.2.899 已修」），别让它沉在聊天记录里。
