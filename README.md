# 玩家角色Boss / Characters Bosses

把《杀戮尖塔 2》**每一幕的 Boss 战换成由原版玩家角色扮演的 Boss**。灵感来自 1 代模组「崩坠（Downfall）」。

- 创意工坊：**玩家角色Boss (Characters Bosses)** — 物品 id `3830639796`
- 前置依赖：**[BaseLib](https://steamcommunity.com/sharedfiles/filedetails/?id=3737335127)**（设置界面用到，硬依赖）
- 一个包同时支持 **正式版 v0.107** 与 **beta v0.111**（游戏只加载 11 KB 外壳，它探测版本后载入对应实现，你不需要管）

## 这是什么

铁甲战士 / 静默猎手 / 故障机器人 / 亡灵契约师 / 储君 —— 这五个原版角色会作为 Boss 站到你对面：

- 有**自己的卡组和遗物**（真的会打出自己职业的牌）；
- 出牌由**固定剧本**驱动，意图可预测（不像随机 AI）；
- 每个档位都有一个**独特特殊效果**（例如「引雷针」「征召上前」「一心化万」）；
- 血量按涅奥的祝福逐幕增长，比玩家更肉。

目前共 **27 个档位**，按「**第几层 + 某角色的第几号**」登记：**一层 7 / 二层 9 / 三层 11**。

- 一层：猎人 1 号奇巧猎 / 故障 1 号黑球机 / 故障 2 号电球机 / 亡灵 1 号灾厄骨 / 储君 1 号碎屑储君 / 储君 2 号轰击储 / 铁甲 1 号愤怒战
- 二层：猎人 1 号涂毒猎 / 猎人 2 号蛇眼猎 / 故障 1 号物理机 / 亡灵 1 号灵魂骨 / 储君 1 号铸剑储君 / 储君 2 号王储 / 储君 3 号仆从储 / 铁甲 1 号放血战 / 铁甲 2 号杂耍战
- 三层：猎人 1 号刀猎 / 猎人 2 号炼药猎 / 故障 1 号能力机 / 故障 2 号事件机 / 故障 3 号状态机 / 亡灵 1 号根除骨 / 亡灵 2 号养手骨 / 储君 1 号无色储君 / 储君 2 号辉星储 / 铁甲 1 号易伤战 / 铁甲 2 号巨石战

**完整的「Boss ↔ 特殊效果 ↔ 控制台点名指令」表见 [`docs/bosses.md`](docs/bosses.md)。**

## 安装

**创意工坊（推荐）**：订阅本模组 + BaseLib，游戏内「模组」里勾上并重启。

**离线包**：把 `CharacterBosses` 文件夹整个解压到 `<Steam>\steamapps\common\Slay the Spire 2\mods\`，
四个文件缺一不可（`CharacterBosses.dll` / `CharacterBosses.json` / `CharacterBosses.pck` / `CharacterBosses.Impl*.dll`）。
详细说明见包内 `安装说明.txt`。

**卸载**：删掉 `mods\CharacterBosses\` 整个文件夹（配置与本机日志在 `%APPDATA%\SlayTheSpire2\` 下）。

## 联机

- 最多 **4 人**。多人时**不增加 Boss 血量**，而是**增加 Boss 数量**（Boss 数 = 玩家数）。
- 每名玩家被一只 Boss **「跟踪锁定」**：该 Boss 的单体攻击、随机攻击、充能球、单体特殊效果只影响这一名玩家；群体攻击照常打所有人。
- 一只 Boss 被打死 → 被它锁定的玩家解除锁定；一名玩家倒下 → 那只 Boss 改锁「锁定层数最少」的幸存者。
- 同一场战斗里**每个角色最多出现一只**（不会同时出刀猎 + 炼药猎）；**主 Boss 的角色整局不重复**。

> ⚠ **联机请所有机器更新到同一版本，并保持同一份玩法设置**。不同版本/不同设置会算出不同阵容 ⇒ 直接「数据不同步」。
> 真遇到不同步，请把**两端的 `mod_log.txt`**（`%APPDATA%\SlayTheSpire2\logs\`）一起发给作者。

## 配置（游戏内「模组配置 → CharacterBosses」）

| 项 | 说明 |
|---|---|
| A1 替换的地图与 Boss 选择 | 按 3 幕列出所有地图（**非原版地图默认关闭**）。勾上的地图会在下面直接展开一片勾选格：**一列 = 一个角色**，竖着排出它在本幕的所有设计；每个角色至少留 1 个（**第三幕 2 个**），取消到下限以下会被界面拦住。主 Boss 从勾选里抽；多人时以房主为准，第 2、3 只「搭子」仍从整幕候补抽 |
| A3 Boss 战 BGM 来源 | ①原版其他 Boss 的音乐（默认）②一代 Boss 音乐（③自制音乐暂未开放） |
| A4 与原本 Boss 共用匹配池 | 开启后，被替换的地图改成「原本 Boss / 角色 Boss」随机抽一边；子项可让进阶 10 第三幕固定一场原本、一场角色 |
| A5 本地对战数据记录 | 默认**关**。开启后每场 Boss 战记一行到本机文件（幕/场、进阶、人数、Boss 血量、回合数、种子等） |
| A6 上传数据 | 仅在 A5 开启时可用；**匿名**上传（不写 SteamID / 昵称），随时可关 |

## 已知问题

- **联机仍可能偶发不同步**：为了兼顾单人与多人，Boss 强度很难平衡，这也是 A5 数据收集存在的原因。
- 与其它模组的兼容性以实际运行为准；出问题时请附 `mod_log.txt`。
